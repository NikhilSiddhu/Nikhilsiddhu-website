What AgriSync Does

  • Collects real-time field data using micro sensors.
  • Sends data to home systems through LoRa communication.
  • Uses Raspberry Pi 5 to process and push data to the cloud server.
  • Lets me access insights on my iPad.
  • Runs an AI predictive model to forecast field conditions for the next 12 hours.
  • Helps take early precautions and decide what to add in the field before problems happen.
